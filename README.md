# Groniva Business Performance & Sales Analytics Dashboard

## Project Overview
An interactive, three-page Power BI dashboard built using sample business data to analyze sales performance, deal conversion, revenue, and collections. The project demonstrates how business intelligence can help stakeholders monitor KPIs and identify performance gaps.

## Dashboard Pages

### 1. Executive Overview
- Total deals, won deals, win rate, and won deal value
- Deal outcomes and lead-source performance
- Monthly deal creation trends

### 2. Sales & Lead Performance
- Deals versus won deals by lead source
- Sales representative performance
- Deal loss reasons and won deal value by product

### 3. Revenue & Collections
- Closing Annual Recurring Revenue (ARR)
- Invoicing and collections analysis
- Collection rate and receivables aging

## Tools & Technologies
- Microsoft Power BI
- DAX for measures and KPI calculations
- Excel for sample data
- Data visualization and business performance analysis

## Key Skills Demonstrated
- KPI development and performance monitoring
- Sales funnel and conversion analysis
- Revenue and collection reporting
- Interactive dashboard design
